Wildberries FBS automation via the official API

If you run Wildberries operations for sellers (fulfillment operator, agency, or a cross-border seller with a Russian warehouse), you know the FBS supply ritual: assemble the supply in the seller cabinet, click boxes one by one, download each sticker, print labels and pray the stack matches the picking order. Integration modules don't cover it — the API does.

wbfbs is an open-source CLI (github.com/Momika808/wbfbs, MIT) that runs the whole cycle:

  • bulk order-to-supply attach — up to 100 orders per request (the old single-order methods were removed by WB in December 2025; if your integration suddenly broke, that's why);
  • order labels as a single PDF in picking-list order — 58×40 / 40×30 mm for thermal printers, or an A4 grid;
  • box (trbx) creation and box stickers as ready-to-print PDF;
  • supply QR code (note: WB only issues it after the supply is transferred to delivery);
  • rate-limit aware: 300 req/min shared FBS pool, and a 4XX response costs 10× the quota — so only 429/5xx are retried.

Common WB API pitfalls this tool already handles

  • 403 Access denied on the whole marketplace-api domain with a perfectly valid «Marketplace» token: a fresh seller cabinet keeps the FBS circuit disabled until five return pickup points are selected in the cabinet (Supplies → Seller warehouse → FBS). No warehouse needed for API access — return points alone unlock it.
  • Stocks reject barcodes: since February 2026, PUT /api/v3/stocks/{warehouseId} accepts chrtId (size ID from the product card) only — barcode upload is disabled (SKUUploadDisabled), and the error is an unhelpful 400 IncorrectRequest.
  • No order-to-box assignment method exists in the current API — boxes can be created, stickered and deleted; assignment is not exposed. Don't promise it to your clients.

Self-hosted by design: runs on the seller's own machine with their personal API token — which is also a WB rule (personal tokens must not be handed to cloud services). Data never leaves your infrastructure.
